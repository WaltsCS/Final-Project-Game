## 📖 Summary  
**One Too Many** is a **top-down, minimalist twin-stick bullet-hell shooter.**  
Players control a virtual data avatar navigating a corrupted Core Chamber System while surviving waves of enemy firewalls and rogue programs.  

⚡ Key Highlights:  
- **One-hit death** system demanding reflexes, precision, and strategy  
- **Fast-paced dodging** and **manual aiming** mechanics  
- **Abstract digital environments** with glitch effects and retro visuals  
- **Fluid, reactive gameplay** designed for high intensity

## 🎮 Gameplay Elements  

### Player Object  
- A glowing data node with a rotatable gun turret  

### Enemies  
- **Wave Programs**: Move in patterns, fire low-damage projectiles  
- **Mini-Boss**: Large enemies, high HP, radial attack patterns  
- **Final Boss**: Complex bullet patterns and area-denial attacks  

### Obstacles  
- Rotating laser beams  
- Moving “death walls”  

### Environment  
- Digital grid arena with glitch/data stream effects  
- Static camera

## 🕹️ Player Controls  
- **W, A, S, D** — Move  
- **→ / ←** — Rotate clockwise / counter-clockwise  
- **F** — Fire  

### Gameplay Features  
- Bullet-hell dodging  
- Manual aiming & rotation  
- Temporary buff pickups  

---

## 🔄 Gameplay Loop  
1. Start at **Level 1**  
2. Survive waves or defeat bosses  
3. Progress through Levels 1–5  
4. **If hit → restart at Level 1**  
5. **Clear all levels → victory**  

Every level increases difficulty, testing **memory, dodging skill, and precision**.

## 🏆 Win Condition  
- **Victory:** Defeat the **Final Boss (Level 5)**  
- **Defeat:** One hit = Restart from **Level 1**  

---

## 🎁 Progression System & Itemization  
### Buffs (temporary):  
- **Overclock Fire** – Increased damage (short duration)  
- **Ping Shield** – One-time shield (rare)  

💡 Buffs drop randomly from enemies.  
⚠️ No permanent upgrades — **progress resets per run**.  

---

## 📊 Scoring System  

| Event               | Points |
|----------------------|--------|
| Defeating Enemy      | 100    |
| Mini-Boss Defeated   | 500    |
| Final Boss Defeated  | 2000   |
| Buff Collected       | 50     |
| Level Completed      | 200    |
| No Buff Bonus        | 300    |
| Flawless Run Bonus   | 500    |

👉 Score resets on death — **high scores track skill & performance per run.**

---

## 🎯 Player Choices & Strategies  
- **Dodge-focused** survival play  
- **Aggressive shooting** for higher score bonuses  
- **Risk vs. reward** decision-making

## 📌 Level Design Overview  

| Level | Enemies          | Mini-Boss | Final Boss | Objective                  |
|-------|------------------|-----------|------------|----------------------------|
| 1     | Light waves      | No        | No         | Survive 60s               |
| 2     | Waves (60s)      | Yes       | No         | Defeat mini-boss          |
| 3     | Heavy waves      | No        | No         | Survive 60s               |
| 4     | Intense waves    | Yes       | No         | Defeat mini-boss          |
| 5     | All enemies + boss | Yes     | Yes        | Defeat mini-boss + Final Boss |

Each level increases **enemy count, bullet speed, and arena hazards.**
